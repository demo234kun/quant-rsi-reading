# LiveOption 论文概要（结构化阅读）

> arXiv:2609.33470v2 ｜ Haochen Luo 等 7 人 ｜ NeurIPS 2026 ｜ 项目页 https://liveoption.github.io/

## 一句话

把期权交易做成"结构化序贯决策"的可复现评测场，用三套任务 + 分层指标检验 LLM agent——结论是：在真实执行与资金约束下，当前 agent 在大多数期权场景跑不赢被动基准，且"均值为正"往往来自少数尾部场次。

## 一、它要解决的问题

现有金融 agent 评测几乎都集中在股票方向性预测（涨/跌），这漏掉了衍生品市场最本质的两件事：

- **收益非线性**：一张期权的盈亏由 Delta、Gamma、Theta、Vega 共同决定，方向对了也可能亏钱（时间价值衰减、波动率回落）。
- **结构而非方向**：真实交易是"多腿组合"的构造与调整（covered call、价差、跨式），不是单点下注。

所以需要一个能把"结构"当一等公民的评测。

## 二、评测环境（2025 年真实市场数据）

| 场景 | 标的 | 资金/底仓 | 决策频率 | 允许结构 | 约束 |
|---|---|---|---|---|---|
| Portfolio Overlay | QQQ、NVDA、AMD、GOOG、TSLA | 1 万股 + 20% 现金缓冲 | 周度（周一收盘） | 收益侧 covered call / 现金担保 put；对冲侧 long put / bear put spread | DTE 7–45（收益）/ 7–60（对冲）；净 Delta 不超过标的 Delta；禁止裸卖 |
| Earnings Bet | 24 只大票，95 个事件案例 | 5 万美元现金 | T-2、T-1 收盘；T 至 T+2 每 30 分钟 | long call/put、垂直价差、跨式/宽跨式 | DTE 7–14；单笔 ≤50 张、≤3 万美元；40% 日亏熔断；T+2 强平 |
| 0DTE Intraday | SPY（2025 周三、周五，102 场） | 10 万美元现金 | 每 15 分钟，09:30–16:00 ET | long call/put、垂直价差、跨式/宽跨式 | DTE 0–7，δ∈[0.20,0.60]；≤5 并发、≤50% 敞口；2% 日亏平仓、3% 预警；15:55 强平 |

执行摩擦统一建模：每张期权佣金 $0.65，同一模拟引擎撮合。每次决策喂给 agent 的上下文包括现货、mark、完整希腊字母、IV、DTE、持仓表，以及压缩后的期权链快照（IV 曲面、货币性分桶、可交易合约清单）。

## 三、指标：结果层 + 行为层

**结果层**

- 组合层（长周期 overlay）：年化收益、Sharpe、最大回撤，以及相对同股数买入持有基准的主动收益与信息比率。
- 事件层（财报、0DTE）：胜率、PnL% 均值与中位、盈亏比、profit factor、不交易比率；均值给 10,000 次 episode bootstrap 区间，跨模型比较用配对符号翻转检验并在比较族内做 Holm 校正；overlay 连续路径改用 stationary block bootstrap。

**行为层**（保留完整决策轨迹：论点文本、意图流、成交日志、希腊字母快照）

- 策略构成：实际交易的期权结构分布。
- 方向性 vs 结构性推理：每笔交易被判定是靠方向观点驱动，还是靠期权机制（希腊字母、IV 与已实现波动之差、Vega 暴露）驱动。
- 仓位与杠杆控制：每笔投入资金、跨场次有效杠杆。
- PnL 分解到 Delta / Gamma / Theta / Vega，用来区分"真懂期权"和"顺带赌对方向"。

## 四、关键结果（8 个模型：DeepSeek-V4-Flash、GPT-OSS-120B、Qwen3-235B-A22B、Llama-3.3-70B、MiniMax-M3、GLM-5.3-Flash、GPT-5.6-Terra、Gemini-3-Flash）

**Overlay：全线跑不赢被动**

- 对冲口径：8/8 模型相对买入持有的主动收益为负，区间 −3.05 到 −13.65 个百分点。
- covered call 口径：7/8 为负。
- 回撤确实有改善（最大 +9.19 个百分点），说明 agent 会买保护，但付出的成本超过收益。
- 和机械规则比：面对固定的 0.30-delta covered call / 保护性 put，panel 在 covered call 口径领先 17.5 个百分点；但"对冲"口径基本持平，而机械规则削掉的回撤约为 agent 的两倍。也就是说 agent 更像"会挑合约的交易员"，而不是"会做风险预算的管理者"。
- 货币性分布正常，没有彩票化倾向（对冲集中 K/S≈0.95–0.99，收益侧 1.01–1.06）；但期限差异是模型属性而非共性偏差（对冲口径均值 6.4–27.1 天）。

**事件层：多数场次是亏的**

- 0DTE：每个模型 102 场里 54–76 场亏损；财报：90–96 个案例里 50–58 场亏损；两个任务的中位数全部为负。
- 分布右偏，尾部极不对称：全样本 38 个上行尾部对 5 个下行尾部。GPT-OSS-120B 在 0DTE 有 10 个上行尾部、90 分位 +9.8%，但中位 −3.20%——均值正而中位负。
- 全年合计（102 场）：GPT-OSS-120B +14.4、MiniMax-M3 +14.4、GLM-5.3-Flash +11.0 个百分点为正；DeepSeek-V4-Flash −74.6、Llama-3.3-70B −60.6、Qwen3-235B −37.1 为负；日胜率区间 25.5%–47.1%。
- 由此得出一条方法论结论：在这种右偏、尾部驱动的收益分布上，**均值是错的总结统计量**，风险控制机制必须用"干预实验"来评，而不是比均值。

## 五、与库内其他论文的关系

- 与 **22 FinForesight** 同属"门槛控制"思路：都强调可复现环境、防信息泄漏、分层指标；差别是 22 评的是文本研究能力，23 评的是可执行交易与非线性收益。
- 与 **11 RMATS**、**08 EvolveTrade** 这类股票组合系统互补：23 说明期权里的"业绩好看"更难伪造，也说明缺少希腊字母级归因时，很容易把方向性运气当成期权 alpha。
- 对做"泛投资与财富管理"的实际含义：overlay 是财富管理最常见的期权用法，本文给出的证据是负面但有用的——现成 LLM agent 还不适合直接接管 overlay 的合约选择与风险预算。

## 六、局限

- 单一年份（2025）、单一市场（美股）、单一 regime（AI 相关大票与高波动单名）。
- 模型为固定快照，快照差异可能掩盖"提示工程"带来的变化。
- 三项任务的结论文本相对简短（v2 距 v1 仅一个月），附录中的行为诊断细节仍需逐节核对。

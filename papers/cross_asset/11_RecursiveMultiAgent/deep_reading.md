# RMATS：递归多智能体组合策略 论文概要（结构化阅读）

> arXiv:2605.25311v2 ｜ Jing Yang（圣路易斯华盛顿大学）、Yichao Wu、Penghao Liang、Jiayi Yang（东北大学）等 8 人 ｜ cs.MA

## 一句话

地缘政治风险（GPR 指数）当一等公民的信号源，四个专家 agent 通过"可保证收敛"的递归协议反复改权重，再由 GPR 触发的熔断器在压力期硬切防御资产——812 个交易日里，事件期 Sharpe 最高、回撤最低。

## 一、要解决什么问题

地缘冲击（军事冲突、贸易摩擦、能源断供、银行倒闭）会同时打穿多类资产，而传统量化框架假设数据生成过程相对稳定，缺"结构性断裂"的响应机制。已有的多智能体组合系统（如 MAPS、MSPM）任务分工做得好，但普遍是**固定单向流水线**：agent 之间没有迭代修正、没有权重收敛的形式化保证、也没有把实时地缘风险当成资金保全的第一类机制。

## 二、方法要点

- **四条功能层**：数据获取 → 专家 agent → 递归协调 → 组合优化。
- **四个专家 agent**：情绪（Sentiment）、研报（Report）、分析（Analysis，含隐马尔可夫状态分类 + 卡尔曼滤波信号融合）、风险（Risk）。
- **递归协调协议**：形式化的 AgentMessage 结构，agent 多轮互相修正，直到权重变化小于 ε = 0.005 收敛；实测中位数 1 轮、均值 1.33 轮、最大 3 轮、97.4% 在 2 轮内收敛、单次最多 39 步。
- **GPR 熔断器**：当月度 Caldara–Iacoviello 地缘风险指数超过 2021–2022 校准分布的 60 分位，风险 agent 直接把组合硬切向防御资产。
- **重要澄清**：本实现的信号生成器是异构**确定性**信号（GPR、动量、HMM 状态、CVaR），**不是 LLM 推理**；论文把 FinBERT 之类 LLM 推断列为未来扩展，并解释月度重平衡频率下 GPR 这类经过同行评审、覆盖 40 年的指数比原始 FinBERT 情绪更干净。

## 三、关键结果（真实 yfinance 数据 + GPR 指数）

- 样本：2023 年 1 月–2026 年 3 月，共 **812 个交易日**。
- **事件期（300 个地缘压力日）**：RMATS Sharpe **1.571**（全场最高）、最大回撤 **7.52%**（全场最低）；对比 MAPS-lite 1.346、GPR 规则基线 0.981。
- **全期**：Sharpe **0.953**，超过 MAPS-lite 0.836（Δ = +0.117）；非事件期 512 天 Sharpe 为 +0.543。
- **熔断器消融**：相对无熔断版本，事件窗口回撤再降 **0.84 个百分点**，Sharpe +0.045——熔断器是本文最主要的实证贡献。
- **诚实的负结果**：把递归协议压成 r = 1（只跑一轮）时 Sharpe 只变 **−0.002**，即**当前配置下递归协调本身几乎不带来业绩增量**，它的价值是"为未来接入真正异构信号预留的架构框架"。

## 四、与库内其他论文的关系

- 是"泛投资与财富管理"栏里少见的**组合层**视角：其余论文多在单标的选股/择时，这篇在资产配置与回撤控制。
- 与 **05 三根缰绳**呼应：这里把"裁判在环内"具体化成可校准的熔断阈值。
- 与 **23 LiveOption** 形成有趣对照：23 说明 LLM agent 做期权 overlay 亏钱，11 说明纯规则化的风险预算在股票组合上可行——合起来的启示是"先做对风险预算，再谈让模型自由发挥"。
- 与 **08/09/10** 的自进化路线不同：这里没有"进化"，只有"递归收敛"，属于保守但可解释的一支。

## 五、局限（作者自陈）

- 递归协议当前无业绩增益（ΔSharpe −0.002），属于架构预留。
- 信号源为确定性指标，未验证 LLM 推理接入后的收益。
- 月度 GPR 频率决定了响应较慢，高频冲击（日内跳空）覆盖不足。

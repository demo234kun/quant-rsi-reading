# SOTA 论文概要（结构化阅读）

> arXiv:2610.10407v1 ｜ Yizhen Xie, Mengyang Liu ｜ NeurIPS 2026 Agenthon Workshop

## 一句话

期权交易的决策层应该抬高一层：让模型选"九类策略族 + 参数"，让确定性解析器去选合约和算仓位——六个月样本外总收益 18.32%、Sharpe 1.60、最大回撤 8.96%，同环境下所有规则与监督学习基线全亏。

## 一、要解决的问题

- 单只股票背后有**几千张合约**（行权价 × 到期 × 看涨看跌），agent 既要选合约又要组合，决策空间巨大且在动态变化。
- 已有做法为了绕开这个复杂度，把策略**固定死**（例如只做平值跨式、只学对冲），代价是市场状态一变就换不了招式。
- 期权还需要同时推理波动率动态、尾部风险、资金效率——这四项要一起做，而不是先看方向再补结构。

## 二、方法：策略层与合约层分离

- **策略级动作**：a = (标的 u，策略族 f，多空方向 ω，期限桶 θ，在 delta 网格上的坐标 κ)。九个有经济含义的策略族覆盖方向、波动、偏斜、曲率四类交易；期限桶锚点为 5 / 14 / 45 / 120 天。
- **动作类型**：开仓、平仓、展期（roll）、不动。
- **三个确定性解析器**：合约解析器（按 Δ 暴露最接近目标选合约）、仓位解析器、对冲解析器（delta 对冲）。模型不管实现细节，只负责"选对结构"。
- **两阶段定价**：先让模型给每个标的提最多 6 个候选策略，只解析和定价这几个候选包，再做最终决策——避免把几千张合约塞进上下文。
- **状态设计**：10 个市场特征（标的收益、已实现波动、隐含波动水平与变化、隐含减已实现的波动楔子、期限结构、偏斜、曲率、期权流、未平仓量变化）+ 新闻与申报的时点文本摘要 + 当前持仓 + 组合层信息。
- **奖励**：对数净值增量 r = log V(t+1) − log V(t)，即扣成本后的组合收益。

## 三、训练：SFT → RL，两段的配方不同

1. **前沿教师生成 + 监督微调**：教师模型在匿名化信息环境（遮掉股票身份、绝对价格、日历时间，只留市场状态与当时可得新闻）里跑出 1000 条轨迹，按年化 Sharpe > 0.75 筛出 **144 条**用于微调。
2. **强化学习（GRPO）**：在组合环境中用净收益训练，基座为 Qwen3.8-27B。

## 四、关键结果（测试期 2025-03-03～2025-08-29）

| 指标 | SOTA |
|---|---|
| 总收益 | 18.32% |
| 年化 Sharpe | 1.60 |
| 最大回撤 | 8.96% |
| Calmar / Sortino | 4.59 / 4.77 |
| 年化波动 | 21.52% |
| 胜率 / 盈亏比 | 29.17% / 4.68 |

基线同环境全部为负：GBDT −49.78%、逻辑回归 −55.45%，等权、GARCH、阈值规则也都亏。论文还附了一个"事后神谕"（用未来真实结果在候选集里选最优）作为策略空间的可达上界参考。

## 五、最有价值的发现：新闻的作用是**非对称**的

- 新闻**帮助**构造教师轨迹（匿名化后加入新闻，轨迹质量更高）——即"用于造专家监督的信息"。
- 但把新闻**保留在强化学习阶段**，样本外总收益从 18.32% 掉到 **−2.72%**，最大回撤从 8.96% 涨到 **31.69%**。
- 同一信息集下，RL 相对纯 SFT 仍是进步（−10.19% → −2.72%，Sharpe −1.25 → −0.16），但要拿到 18.32%，必须在 RL 阶段**剥离新闻**。

这条结论对"多模态 / 新闻增强交易 agent"的主流叙事是一个直接的反例：**信息有用 ≠ 该留在优化回路里**。

## 六、与库内其他论文的关系

- 与 **23 LiveOption** 刚好互补：23 是评测框架，证明现成 agent 在期权里普遍跑不赢基准；25 是训练方案，说明"把决策层抬到策略级 + 两段式后训练"是能跑出正收益的一条路。
- 与 **11 RMATS** 的"组合层视角"一致：都在操心仓位与风险，而不是单点方向。
- 与 **06/07/12** 的"把反馈搬进权重"同源：25 用 GRPO 直接优化组合收益，属于同一谱系。
- 与 **09 SHARP** 形成对照：09 用人类可读规则约束策略空间，25 用"九类策略族 + delta 坐标"约束动作空间，都是"把搜索空间结构化"的不同实现。

## 七、局限

- 只有六个月样本外、十个标的，且测试期正好是高波动年份，跨 regime 稳定性未知。
- 策略族固定为九类，超出这九类的结构（例如日历价差、比率价差）无法表达。
- 胜率仅 29.17%，靠 4.68 的盈亏比取胜——这是典型的"少数大赢"分布，对尾部事件的容忍度需要额外检验。
- 结果是单一策略叠加 delta 对冲，未做多标的相关性管理与组合层风险预算。

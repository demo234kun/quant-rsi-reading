# TradingGroup 论文概要（结构化阅读）

> arXiv:2508.17565v1 ｜ Feng Tian, Flora D. Salim, Hao Xue ｜ 新南威尔士大学（UNSW）

## 一句话

五个角色分工的 LLM 交易 agent + 三处自我反思 + 动态止损止盈 + 一条把"交易过程"自动标成训练数据的流水线——回测胜过规则、机器学习、强化学习与既有 LLM 交易策略。

## 一、两个缺口

1. **没有"交易过程"数据**：主流金融 LLM 用固定领域知识训练，缺"市场状态 + agent 决策 + 结果"这种端到端交易经验，因而难以在真实市场里持续改进。
2. **自我反思不闭环**：现有反思多靠检索增强（RAG）从历史案例里捞相似片段，但没把**执行结果、agent 日志、风险信号**整合成一致的反馈回路，分不清哪次历史决策真好、哪次真坏，也就谈不上强调整。

## 二、系统组成

**五个 agent**

- 新闻情绪 agent：带 MCP 客户端接在线检索（如 Serper），先算每条新闻的影响分（关键词/长度规则分 0.55 + Qwen3-Reranker 给出的"有冲击力"概率 0.25 + 0.20 的底分偏置），取前 k 条后用向量相似度去重，再并行分析汇总成市场情绪分。
- 财报 agent：用优化过的 RAG 读季报年报，为其他 agent 提供当前财务状态。
- 选股预测 agent：技术因子 + 其他 agent 分析 + 自我反思，预测价格趋势。
- 风格偏好 agent：结合账户状态、历史表现与其他分析，输出当前偏好的交易风格及置信度。
- 交易决策 agent：汇总上游全部信号，回看历史盈亏案例，经自我反思给出买/卖/持。

**三个配套模块**

- **自我反思**：嵌在预测、风格、决策三处，从过去的成功与失败中提炼可迁移的经验，用于相似情形下的再推理。
- **动态风控**：可配置的动态止损、止盈，以及仓位规模调整。
- **数据合成与自动标注流水线**：自动记录并评估各个 agent 的工作数据（含思维链轨迹），产出适合参数高效微调（PEFT）的指令数据，再用后训练反哺模型。

## 三、关键结果

- 在五个真实股票数据集上回测，综合表现优于规则策略、机器学习策略、强化学习策略以及现有 LLM 交易策略。
- 由该流水线合成的训练集在后训练后确实提升了同一框架内的回测表现（论文把它作为数据流水线有效性的证据）。

## 四、与库内其他论文的关系

- 与 **08 EvolveTrade** 的差别：08 是"每天改自己的策略文本"，13 是"反思 + 用自己产生的数据去微调模型"——后者把经验固化进权重，前者留在上下文里。
- 与 **07 QuantEvolver** 同向（都走"把反馈搬进权重"），但 07 用的是强化微调，13 用的是数据合成 + 监督式后训练。
- 与 **09 SHARP** 互为镜像：09 追求可审计的规则束，13 追求数据的自动增殖，两者都在解决"信用分配"，路径不同。
- 与 **18 KISS** 在"经验外化"这一点上相通：都是把隐性经验变成可复用资产，一个在仿真建模，一个在交易决策。

## 五、局限

- 五个 agent 全部依赖同一个基座模型的多次推理，成本与延迟在实盘频率下压力大。
- 反思机制仍以文本经验为主，没有形式化的收敛保证（对比 **11 RMATS** 的协议化收敛）。
- 论文以回测为主，未见按市场状态分层的稳健性分析。

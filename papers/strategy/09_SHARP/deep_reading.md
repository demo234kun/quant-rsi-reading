# SHARP 论文概要（结构化阅读）

> arXiv:2605.06822v1 ｜ Xiwen Chen, Wenhui Zhu, Songzhu Zheng, Kashif Rasul, Yueyue Deng, Huayu Li ｜ Morgan Stanley / ASU / Columbia / University of Arizona

## 一句话

把交易策略压成一份"人能审计"的条件—动作规则清单（rubric），亏了钱先归因到具体规则编号、再做一次只改一条的原子编辑，改完必须过 walk-forward（滚动前向）验收关——用"结构 + 归因"替代自由文本的 prompt 自进化。

## 一、要解决的两个病

现有自我改进型交易 agent 普遍靠自由文本改写自己的"状态"（分层记忆、投资信念、prompt 优化都属此类）。作者认为这在低信噪比、奖励延迟的市场里有两个致命问题：

1. **搜索空间无界**：一段自由 prompt 里任何位置、任何时刻都能改，等于在一个无界高维离散空间里搜索；而奖励（盈亏）本身噪声极大，优化器分不清"系统性逻辑错误"和"市场随机波动"，于是出现**策略漂移**（policy drift）。
2. **信用分配失效**：优化器只拿到一个汇总的盈亏数字，没有任何机制把某笔亏损归到某个局部逻辑错误上，于是只能整段重写，而不是精准修正。

## 二、方法：三 agent 的闭环

- **规则束（rubric）**：策略 = 一组有上下界的条件—动作规则，例如"若 VIX 高于 25，则把看多收益预期下调 30%"。金融判断住在规则里，LLM 的职责被压缩成"把非结构化新闻映射到规则的条件空间"，这比让它自由推理收益要窄得多、可查得多。
- **归因 agent**：跨多个样本回看，把盈亏失败定位到具体规则编号，把系统性缺陷和市场噪声拆开。
- **进化 agent**：在符号空间里做三类原子编辑——改一条规则的阈值、为未覆盖的情形加一条新规则、删掉一条老在误触发的规则；每轮编辑数量有上限，保证搜索可解。
- **验证门**：只有改动在留出数据上确实变好才接受，防止对最近噪声过拟合。
- 全部规则、全部编辑、全部归因轨迹都可读、可版本化、可审计。

## 三、关键结果

- **数据与设置**：三个风格迥异的股票板块（AI 科技、生物科技、可选消费）× 四个 LLM 骨干，严格 walk-forward 协议。
- **提升幅度**：SHARP 把通用初始启发式稳定改造成有竞争力的策略，紧凑模型平均提升 10–20 个百分点（作者举例 GPT-4o-mini）。
- **反证实验（最有说服力的一条）**：把结构化 rubric 换回自由形式的反思，AI 科技板块的收益从大约 +33% 掉到 −12%，说明失败就出在变异算子缺少结构约束。

## 四、与库内其他论文的关系

- 与 **08 EvolveTrade** 正好构成对照组：08 是让 agent 每天重写 policy 文本（自由形态），09 是让 agent 只改规则束里的原子条目（有界形态）。两者都能自进化，但信用分配能力差一个量级。
- 与 **01 AQuA** 共享一个判断：真正稀缺的不是"能提出想法"，而是"能把失败归因到可修的部件"。
- 对 **11 RMATS** 这类"多 agent + 熔断"的系统是个补强：规则束本身天然可审计，适合放进需要合规留痕的场景。

## 五、局限

- 规则束是人类可读的符号空间，表达能力天然弱于程序级策略（对比 **10 AlgoEvolve**、**14 FactorEngine** 那种"策略即可执行代码"的表述）。
- 只在股票板块上验证，未涉及多资产、期权等非线性结构。
- 结论依赖四个骨干模型的推理能力，模型换代后"紧凑模型 +10~20 个百分点"这一数量级可能变。

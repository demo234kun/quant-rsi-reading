## 2. 核心精读问答

### Q1 研究问题：这篇文章试图建立什么？

把整个 RSI 领域压成一个**最小回路 + 三根缰绳**的分析框架。

**最小回路（四个零件）**：
```
改进者 → 目标系统 → 验证 → 结果回流（训练改进者）→ 外部信息流入
```

文献里"RSI"混着四种东西：
1. 用自己输出当训练数据（STaR、自奖励 LM）——改训练数据层
2. 改自己代码/harness（DGM）——改实现层
3. 自动化 AI 研究过程（AQuA、Astar、XALPHA）——改研究过程层
4. 改自己的评估器——最少人碰、最多人怕

### Q3 解决方案：三根缰绳

**缰绳一·裁判（评估器在环内还是环外）**

| 拓扑 | 代表 | 24 代后报告/真实裂缝 |
|---|---|---|
| 密封外部裁判 | AQuA | -0.002（几乎重合） |
| 确定性程序裁判 | FunSearch/AlphaEvolve/DGM | — |
| 学习型替代裁判 | Astar（AUC 0.8487） | +0.48 |
| 自我裁判 | 自奖励 LM | **+1.19**（报告是真实的 2.5 倍） |

裂缝来自误差复利：替代裁判误差被"赢家诅咒"选中，自我裁判误差被自我美化放大。

**缰绳二·燃料（不能吃自己的尾气）**
- **RSI 第二定律**：自我改进可持续速率 ≤ 外部验证信息流入速率
- 纯自我再训练 12 代后标准差从 0.9 缩到 0.06（模型坍缩）；混 5% 外部监督稳态 0.36，20% 稳态 0.64
- 坍缩的是尾部：P(输出>1.5) 归零，罕见优秀答案最先消失
- 燃料纯度排序：自奖励 LM < Absolute Zero < AlphaEvolve < **Astar（真实 A/B 反馈）**

**缰绳三·传动（takeoff 是 τ 越过 1 的后果）**
- τ：一代改进中传回改进者、转化为下一代改进能力的比例

| τ | 30 代后能力 |
|---|---|
| 0.5 | 7.6（平台） |
| 1 | 17.2（线性） |
| 1.3 | 79.3（复利） |

> 今天所有已部署系统 τ 都 < 1；只有改进作用于"改进过程的瓶颈本身" τ 才可能 >1（Dream-RSI 自适应 Lasso 求解器是第一件实物）

### Q5 核心材料：四个家族项目地图

1. **数据飞轮**（燃料）：STaR/SPIN/自奖励 LM/SEAL/Absolute Zero/R-Zero——共同发现是平台期
2. **架构搜索**（裁判）：FunSearch/AlphaEvolve/ADAS/DGM/OpenEvolve——裁判全是确定性程序
3. **研究过程**（工业主战场）：AQuA/Astar/XALPHA/AlphaMemo——裁判拓扑最杂、最接近生产
4. **尺子**（不是选手）：MLE-bench/RE-Bench/METR——测量自我改进速度

**三篇 frontier 论文**：
- DGM：把"证明有益"换成"实证有益"（SWE-bench 20%→50%）
- Absolute Zero：零数据自我进化，燃料是执行器的比特
- 综述 2607.07663：74% 语料发表于 2026 年

### Q6 创新点与可借鉴点

- **理论创新**：三根缰绳统一框架；τ 传动概念；RSI 第二定律
- **可迁移**：评估任何 RSI 系统时，分别核查裁判拓扑、燃料纯度、τ 值
- 三根缰绳未造好的洞：构造上密封的裁判、信息计量（每代外部比特数）、τ 测量（跨任务继承量）

### Q7 不足与局限

1. 框架本身不产出新实证，数字分散在各一手论文
2. 三个开放问题（密封裁判/信息计量/τ 测量）今天都无解
3. τ 与第二定律偏概念，工程上难直接测量

## 3. 范式提炼

### 逻辑范式
```
最小回路 → 三个失控点（裁判/燃料/传动）→ 逐一接缰绳 → 用一手工作验证
```

### 技术范式
> 用"谁来判断好坏（裁判）、信息从哪来（燃料）、改进能否复利（τ）"三问，给任意递归自我改进系统定位风险。

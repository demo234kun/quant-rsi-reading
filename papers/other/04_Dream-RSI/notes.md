# Dream-RSI：在历史发现树上做梦 —— 解读笔记

> **代码**：github.com/zhengkid/Dream-RSI ｜ 站点：dream-rsi.com
> **微信解读**：[wechat.md](./wechat.md)

## 一句话定位

不重训模型、不改权重，让"**寻找知识的方法**"自己在历史留存的发现树上"做梦"、进化，再回到真实世界跑一次。元层（探索策略）自改进，执行层（coding agent）一行不改。

## 它解决什么问题

所有现代发现系统都有同一个 loop：提候选 → 跑评估 → 看结果 → 修改 → 再跑。真正卡住 RSI 的是 loop 外面那层：**探索策略本身怎么变好**。

两难：
- **固定策略**：搜索空间一大就失效，算力反复撒进无效方向；
- **在线优化策略**：元层反馈延迟且昂贵——评估一个探索策略要观察它塑造的整个后续发现过程，几十上百个 proposal-evaluation 周期。

## 关键洞察：完成的发现史本身就是模拟器

一次探索跑完，留下的不只是最终答案，而是一棵**结构化发现树**：每个节点存着那次尝试的完整观测（得分、成本、报错、工作区状态）。

一个新的探索策略可以在这棵树上"重走"：选不同分支子集、不同顺序、不同并行分组、不同停止点——所有结果都已存好，**重走只读记录，不跑一次执行**。

谱系位置：experience replay (Lin 1992) → Dyna/World Models → offline RL/FQE → Dream-RSI 选择**不学世界模型**——回放模拟器是确定性的、零模型偏差的，代价是只覆盖已实现的搜索空间。

## 形式化

- 发现树 𝒯，可选节点 A(𝒯) = {root} ∪ {叶子}；
- W 个并行 worker；策略动作是一个批量 C ⊆ A(𝒯)，|C| ≤ W；
- 在线 rollout 最多 K₁ 轮；做梦阶段用**完全相同的决策接口**，只是转移函数从真实执行换成读取已存结果。

> "接口同一"是被忽略的好设计：做梦评估的对象，与最终部署的对象是同一个策略本身，不是近似。

回放打分函数（论文式 1）：

```
V = max_v s_v − β₁·N + β₂·N / max(1, k*)
```

- 发现质量（轨迹里最好得分）
- 执行成本（揭示的非根节点数 N）
- 并行奖金（平均每轮尝试数）
- β₁、β₂ 是隐藏价值函数——"什么算好探索"被烤进回放分数；改 β 就改了什么会被梦到。

## 数字（Lasso regularization path 战场）

- 17 个合成实例做发现，6 个 held-out 下游数据集做泛化评估（跨生物与非生物域）；
- 对照：sklearn、glmnet、SimpleTES（GPT-OSS-120B，预算 51,200 代）、Recursive Fixed Exploration 控制基线；
- 5 轮递归。

| 配置 | runtime | discovery 调用 |
|---|---|---|
| Gemini-3.1-Pro 基线 | 3587.1 ms | 550 |
| Gemini-3.1-Pro Dream-RSI | **2931.0 ms** | **317** |
| Gemini-3.7-Flash 基线 | 2516.7 ms | 3200 |
| Gemini-3.7-Flash Dream-RSI | **2350.6 ms** | **1879** |

对 SimpleTES 约两个数量级调用差（部分设置 162 倍）；发现的求解器在全部 6 个 held-out 数据集跑赢 sklearn 与 glmnet。

**真正的成果不是省时间，是发现了一个新算法**：在 active-set 优化内部引入自适应性——strong-rule screening + 基于 Cauchy–Schwarz 的 KKT 剪枝，剪枝失效时回退全量刷新；再叠 lazy Gram 矩阵与硬件感知实现。**元层探索发现的是算法，不是超参。**

> 这是"τ 在过程层可能大于 1"的第一份实物证据。

## 两个独立误差源（论文没写 limitation，搬去量化的人要自己补）

| 误差源 | 是什么 | 怎么修 |
|---|---|---|
| **反事实缺口** | 模拟器只覆盖已实现空间；目标策略想走的分支没被探索过就答不上来 | 靠更多真实探索（实验⑥：regret 随覆盖率 0.299→0.073） |
| **非平稳** | 存的是旧世界答案；regime 翻转后梦到的是答案全反的教科书 | 靠 PIT 加权或重新探索（实验⑥漂移版：regret 1.05–1.19，不随覆盖率下降） |

## 对量化的直接启示（微信解读里的合成实验）

把做梦机制搬进合成 alpha 搜索世界：30 个候选分支、稀疏真实 alpha、平稳 vs regime 漂移（第 20/40 轮符号反转型翻转）。

| 策略 | 平稳世界终值 | 漂移世界终值 |
|---|---|---|
| 固定探索 | 8.84 | 2.75 |
| plain dream（全历史回放） | 29.36 | 8.71 |
| **PIT dream（按新近度加权）** | 29.47 | **10.06** |

> PIT 做梦在平稳世界是免费保险，在漂移世界是救命绳。**回放权重必须带时间衰减，衰减速率与 regime 半衰期同量级**。

## 六个应用方向（微信解读给出的清单）

| 方向 | 做不做 | 理由 |
|---|---|---|
| 因子/alpha 挖掘环 | ✅ 做 | 密封 holdout + 回测双层裁判；先装 PIT vintage + purged CV |
| 研究策略自改进（Dream-RSI 式） | ✅ 做，带 PIT | 从今天起把发现树结构化存下来 |
| 数据管线工程自改进 | ✅ 做（风险收益比最好） | 改的不是 alpha，是生产 alpha 的机器；单元测试 + PIT 审计 |
| 训练代码与超参演化 | ⚠️ 谨慎 | 验证回测本身可被 overfit hack；必须含密封 holdout + deflated Sharpe |
| 实盘策略自修改 | ❌ 不做 | PnL 太慢太噪、错误不可逆 |
| 评估器自修改 | ❌ 永不做 | AQuA 用整篇论文论证；自我裁判 24 代后报告/真实裂缝 +1.19 |

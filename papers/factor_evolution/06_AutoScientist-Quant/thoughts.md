# AutoScientist-Quant 个人思考

## 它和 AQuA 是两种世界观

AQuA 的隐含假设是"量化研究的两个子问题（找因子、调模型）差异太大，硬连会引入泄漏"，所以分而治之。AutoScientist-Quant 的隐含假设是"研究过程本身是统一的预算分配问题，一个 controller 应该看到全局"。

读完两篇再下结论之前，最该问的是：**controller 看到全局后，它真的做出了更优的预算分配，还是只是把两个子问题的泄漏通道合并了？** 论文说 feedback/test window 不相交，但 controller 同时调因子和模型时，"选哪个库"这个决策本身会不会偷偷用了 test 信息？这是要读实验节的关键点。

## 对个人系统的启发

"按剩余预算决策"这个思路很便宜：自己做研究时，可以给每个 session 设一个总预算（比如 50 次实验），前 40 次允许 pivot，后 10 次只做最稳的 improve。这个纪律不需要任何 LLM 也能执行。

## 与本库其他文章的关系

- 它是 01_AQuA 的**同期对照组**，两种 RSI 哲学的直接碰撞。
- 它的 controller 调度思路，和 05 框架里的"传动 τ"有关——如果 controller 的决策被后续 run 继承，τ 就 >0；如果每次 run 从零开始，τ=0。

# Astar：8B 专用模型在生产环境跑 RSI —— 解读笔记

> **论文**：Astar（阿里 × 浙江大学）
> **arXiv**：[2608.27287](https://arxiv.org/abs/2608.27287)
> **部署场景**：2026 年 7 月，阿里 Lazada 广告召回系统，真实生产环境
> **微信解读**：[wechat.md](./wechat.md)

---

## 一句话定位

Astar 是一个 8B 专用模型，**只会一件事：提出 AI 系统的下一步演化方向**。它把过去由资深工程师做的"下一步改哪儿"这件事，训练进了权重里，并在 Lazada 生产环境无人值守跑了 20 轮。

## 为什么"提方向"是最后一块没自动化的拼图

AI 系统迭代四步：**提方向 → 写代码 → 训练 → 评估去留**。后两步已自动化，第一步没有，因为：
- 太吃综合判断（业务+数据+架构+训练动态）
- 验证太贵（一次完整训练以天计）

直接问通用大模型？论文真测了：

| 提案者 | 单提案真实执行成功率 |
|---|---|
| GPT-5.5 | 0.3071 |
| 人类专家 | 0.3229 |
| **Astar-8B** | **0.6786** |
| Astar-0.6B | 0.5435 |

> 通用模型和人类专家打平，且都不及格。瓶颈不是聪明，是**经验放在哪里**——通用模型没读过这个系统的失败记录。

## 核心方法：不注入，训练

### 数据工程：把几百条 commit 变成几万条样本

四个坑：记录太少 / 噪声太多 / 方向空间太大 / 验证太慢。

解法：
1. **Pairwise 扩展**：任意两版本配对比较，几百条 → 几万条；胜负看完整 loss 曲线，不看单点。
2. **三段过滤**：可达性分析（删死代码）→ AST 归一（删 print/注释/格式）→ 配置白名单（只留算法变量）。
3. **语义过滤**：LLM 判断有没有演化意图，产出三层级 hints（科室→检查→剂量）。

### 三阶段训练（培养住院医）

| 阶段 | 数据量 | 学什么 |
|---|---|---|
| Mid-training | 112B tokens | 在完整演化历史上 next-token 预测，学会写结构化方向 |
| SFT | 81.1M 正样本 tokens | 只跟成功病例学（复合指标：末步 loss + 末 k 步均值 + 稳定性惩罚） |
| RL (GRPO) | 8.06M tokens | 放手探索新方向 |

消融：base RM@1 = 0.0380 → mid-training 0.6041 → +SFT 0.6853 → +RL 0.7183。**最大台阶是领域经验一次性注入**。

## 关键组件：奖励模型（教练）

验证一个方向要几天，RL 探索要即时反馈。解法是训一个二分类奖励模型："这个方向会不会降 loss"。

| 判断"方向有没有用"的 AUC |  |
|---|---|
| **Astar 奖励模型** | **0.8487** |
| 人类专家 | 0.6142 |
| 最强通用模型 | 0.5997 |

身兼三职：RL 奖励函数 / 候选排序器 / 离线指标裁判。

> ⚠️ 0.8487 翻过来看：**约 15% 的排序是错的**。这 15% 同时流进策略梯度、候选排序、离线指标三个地方。论文用增量校准（周期性抽样真实验证）+ 部署前真实 A/B 做外圈刹车。

## 递归闭合：改进的产物反过来改进改进者

```
Astar 提方向 → Code Agent 实现 → 训练评估 → 部署
   ↑                                              ↓
   └── 结果被采样/降噪/结构化成新样本，回流训练 Astar ┘
```

- 没有这条回流，Astar 是静态模型，目标系统一旦演化到训练时没见过的新状态就够不着。
- 有了这条回流，20 轮部署里它一直在变强。
- 改进的产物反过来改进改进者本身——这就是论文标题里 "self-evolving" 的含义。

## 结果（Lazada 广告召回）

- 两周、20 轮连续迭代，离线 Hitrate@200 累计 +23.6%；
- 随后 5 天线上 A/B：**GMV +4.86%、广告收入 +1.82%、点击 +0.84%、订单 +1.79%**（p<0.05）；
- 效率表冲击最大：人工每周 Θ(1)–Θ(10) 个方向、每方向 Θ(1)–Θ(10) 小时人力 → Astar 每周 Θ(100) 个方向、每方向 Θ(1)–Θ(10) 分钟人力。

## 两个真实提案案例

1. **RQ-VAE 码本结构**：decoder 共享 FFN 同时拟合粗/细两层码本，互相打架 → 换 MoE，每层一个专家，按层级索引路由；FLOPs 中性。
2. **Muon 优化器改造**：Muon 把梯度矩阵所有奇异值拉平到 1，但推荐场景梯度谱里噪声 bulk 被一起放大 → 用 Marchenko-Pastur 边界做频谱降噪，边界之上正常处理、之内衰减；无学习参数。

> 一个模型从自己系统的训练动态里，提出了一个有随机矩阵理论背书的优化器改造。

## 八个值得追问的问题

1. **评估有循环**：离线指标用他们自己的奖励模型当裁判，奖励模型同时是 RL 奖励和排序器。
2. 缺三个基线：in-context 历史注入、奖励模型+简单搜索、AlphaEvolve 式演化+同一奖励模型。
3. Pairwise 扩展归因模糊（跨多轮的组合拳）。
4. loss ≠ 业务（召回 +23.6% 到端到端 GMV +4.86% 之间隔着排序和出价）。
5. 单系统、单窗口、p 值给了但置信区间没给。
6. 112B tokens 与"每系统数百条记录"之间的张力——多少能力来自跨系统先验。
7. 三层级 hints 是预定义分类法，探索天花板被它框住。
8. 可复现性分层：内部数据/模型/阈值，外部能复现管线复现不了结果。

## 2. 核心精读问答

### Q1 研究问题：这篇论文试图解决什么问题？

**背景**：所有现代发现系统都有 loop（提候选→跑评估→看结果→修改→再跑）。真正卡住 RSI 的是 loop 外那层：**探索策略本身怎么变好**。

**两难**：
- 固定策略：搜索空间一大就失效，算力撒进无效方向
- 在线优化策略：元层反馈延迟且昂贵——评估一个探索策略要观察它塑造的整个后续发现过程（几十上百个 proposal-evaluation 周期）

**目标**：用已完成的发现史作为零成本模拟器，让探索策略离线进化。

### Q2 相关研究 / 谱系

experience replay（Lin 1992）→ Dyna / World Models → offline RL / FQE → **Dream-RSI**。

本文关键选择：**不学世界模型**——回放模拟器是确定性的、零模型偏差，代价是只覆盖已实现的搜索空间。

### Q3 解决方案：论文如何解决？

**① 核心洞察：完成的发现史本身就是模拟器**
- 一次探索留下一棵**结构化发现树**，每节点存完整观测（得分、成本、报错、工作区状态）
- 新策略在树上"重走"：选不同分支、顺序、并行分组、停止点——**只读记录，不跑执行**

**② 形式化**
- 发现树 𝒯，可选节点 A(𝒯) = {root} ∪ {叶子}
- W 个并行 worker；策略动作是批量 C ⊆ A(𝒯)，|C| ≤ W
- 在线 rollout 最多 K₁ 轮；做梦阶段用**完全相同的决策接口**，只是转移函数从真实执行换成读取已存结果
> "接口同一"是关键：做梦评估的对象与最终部署对象是同一个策略本身

**③ 回放打分（论文式 1）**
```
V = max_v s_v − β₁·N + β₂·N / max(1, k*)
```
- 发现质量（最好得分）、执行成本（揭示节点数 N）、并行奖金
- β₁、β₂ 是隐藏价值函数；改 β 就改了什么会被梦到

### Q4 可复现细节

- **战场**：Lasso regularization path
- **数据**：17 个合成实例做发现，6 个 held-out 下游数据集做泛化评估（跨生物/非生物域）
- **对照**：sklearn、glmnet、SimpleTES（GPT-OSS-120B，预算 51,200 代）、Recursive Fixed Exploration
- **设置**：5 轮递归
- **代码**：已开源（GitHub 链接如上）
- **模型**：Gemini-3.1-Pro / Gemini-3.7-Flash（执行层）

### Q5 实验部分

| 配置 | runtime | discovery 调用 |
|---|---|---|
| Gemini-3.1-Pro 基线 | 3587.1 ms | 550 |
| Gemini-3.1-Pro Dream-RSI | **2931.0 ms** | **317** |
| Gemini-3.7-Flash 基线 | 2516.7 ms | 3200 |
| Gemini-3.7-Flash Dream-RSI | **2350.6 ms** | **1879** |

- 对 SimpleTES 约两个数量级调用差（部分设置 162 倍）
- 发现的求解器在全部 6 个 held-out 数据集跑赢 sklearn/glmnet
- **真正成果是发现一个新算法**：active-set 内引入自适应性——strong-rule screening + Cauchy–Schwarz KKT 剪枝，失效回退全量刷新；叠 lazy Gram + 硬件感知实现。**元层探索发现的是算法不是超参**

**两个独立误差源（论文未写 limitation，搬去量化要自己补）**：

| 误差源 | 怎么修 |
|---|---|
| 反事实缺口（模拟器只覆盖已实现空间） | 更多真实探索（regret 随覆盖率 0.299→0.073） |
| 非平稳（旧世界答案，regime 翻转后全反） | PIT 加权或重新探索（漂移版 regret 1.05–1.19） |

**对量化的合成实验（30 候选分支、稀疏 alpha、平稳 vs 漂移）**：

| 策略 | 平稳世界 | 漂移世界 |
|---|---|---|
| 固定探索 | 8.84 | 2.75 |
| plain dream（全历史） | 29.36 | 8.71 |
| **PIT dream（新近度加权）** | 29.47 | **10.06** |

### Q6 创新点与可借鉴点

- **理论创新**：发现树即确定性零偏差模拟器；做梦与部署"接口同一"
- **方法创新**：元层自改进、执行层冻结；PIT 回放加权
- **可迁移**：从今天起把研究发现树结构化存下来；数据管线工程自改进（风险收益比最好）
- **核心结论**：PIT 做梦在平稳世界是免费保险、漂移世界是救命绳；回放权重必须带时间衰减，速率与 regime 半衰期同量级

### Q7 不足与局限

1. 只覆盖已实现搜索空间（反事实缺口）
2. 非平稳下回放答案可能全反
3. β 权重隐含价值判断，可能把探索引向偏差
4. 论文未明确写 limitation
5. 成果目前集中在 Lasso 单一战场，通用性待验证

## 3. 范式提炼

### 逻辑范式
```
痛点（探索策略如何变好，在线评估太贵）
  → 洞察（发现史即模拟器）→ 方法（树上做梦，接口同一）
  → 验证（runtime/调用数 + 新算法发现）→ 补误差（覆盖率+PIT）
```

### 技术范式
> "在自己的历史轨迹上离线重放以改进搜索策略"——执行层冻结、元层进化；用确定性回放替代世界模型，用 PIT 加权对抗非平稳。

## 4. 后续研究拓展

- **值得做**：因子/alpha 挖掘环（先装 PIT vintage + purged CV）；数据管线工程自改进
- **不做**：实盘策略自修改（PnL 慢、错误不可逆）；评估器自修改（永不做）
- **谨慎**：训练代码/超参演化（必须含密封 holdout + deflated Sharpe）
- **上位类**：自主机器学习、元学习
- **下位类**：探索策略优化、发现树回放、算法发现
- **同位类**：AQuA、AlphaEvolve、FunSearch、World Models
- **数据类型**：发现树、合成优化实例、held-out 下游数据集

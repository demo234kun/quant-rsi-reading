## 2. 核心精读问答

### Q1 研究问题：这篇论文试图解决什么问题？

**背景**：量化投研高度依赖人工反复假设 - 回测迭代；现在 LLM 智能体可以自动写实验、跑回测，但存在致命缺陷：智能体可以污染自己的训练证据。

**现存痛点**：
- 普通 AI 科研智能体（如 AI Scientist）的缺陷：作者智能体与评审智能体共享同一套盲点；一旦发现带未来信息泄露的"伪有效因子"，该错误样例被存入记忆，会在后续迭代不断放大污染，出现证据污染（evidence contamination）/ 回测过拟合，在量化领域代价极高。
- 传统自动因子挖掘：搜索空间大、容易过拟合；大多是一次性搜索，缺少基于历史实验证据的递归自改进闭环，无法像量化研究员一样，从大量失败实验中学习、迭代假设。
- 自改进 AI 的现有工作大多聚焦模型权重层面的自我优化；在研究假设 / 实验方案层面的递归自改进，在量化金融场景缺乏严格受控验证。

**研究动机**：能不能构建一套自主投研系统，从过往实验结果（成功 / 失败）学习，持续生成更好的因子 / 模型假设；同时强制隔离机制，杜绝证据污染、数据泄露。

**任务目标**：构建两套独立、密封沙箱约束的 LLM 智能体闭环：
1. 符号因子挖掘子系统：生成数学表达式形式 Alpha 因子，回测验证，迭代优化因子组合；
2. 时序模型开发子系统：生成时序模型配置，训练、评估，迭代模型架构 / 超参；

两个系统完全隔离，各自独立完成「假设生成 → 构造实验 → 沙箱评估 → 证据归档 → 下一轮假设改进」闭环，实现流程层面的递归自改进，而不是模型权重自训练。

### Q2 相关研究：有哪些相关研究？

**已有方法分类**：
- **自动因子挖掘（传统量化）**：遗传编程、符号回归，直接搜索数学表达式因子。优势：可生成可解释符号因子；缺陷：大多为单轮搜索，没有从历史失败实验中学习的递归闭环，极易过拟合、缺少假设迭代能力。
- **通用科研智能体（AI Scientist 等）**：LLM 多智能体自动写代码、设计实验、运行、总结，闭环做科学发现。优势：通用科研闭环；缺陷：作者 / 评审智能体共享记忆与盲点，证据污染，在金融时序场景会被未来信息泄露击穿，没有沙箱隔离约束。
- **LLM 驱动量化智能体**：LLM 生成因子、写回测代码。优势：利用大模型领域知识生成候选因子；缺陷：缺少严格隔离，容易重复生成同类坏假设，迭代过程放大数据泄露。
- **递归自改进 AI**：大多聚焦基础大模型权重自微调；很少在假设生成、实验设计层面做流程自改进，金融时序场景验证不足。

**研究缺口（本文定位）**：现有工作没有解决：在自动迭代投研假设的同时，防止证据污染。AQuA 的核心缺口填补思路：将整个投研系统拆成两套完全隔离的沙箱闭环，沙箱冻结数据划分、评估器，智能体仅允许受限操作；智能体只能修改因子表达式 / 模型配置，不能修改底层数据与评估规则，切断泄露路径。

### Q3 解决方案：论文如何解决这个问题？

**整体框架：AQuA = 两个完全独立、互不通信的密封沙箱闭环系统**
1. Part I：Symbolic Factor Discovery（符号因子挖掘多智能体流水线，加密资产）
2. Part II：Trainable Time-Series Model Development（可训练时序模型配置迭代闭环，美股股票）

两个系统不共享智能体、记忆、候选池、研究状态，各自独立跑相同的 5 阶段闭环：
假设生成 → 构造候选 → 沙箱执行实验 → 评估并归档证据 → 使用历史证据更新假设生成器 → 下一轮

核心设计：Sealed Sandbox（密封沙箱），沙箱内固定：数据划分、标签定义、评估指标、回测规则；智能体仅能提交：因子表达式（Part I）或模型配置 diff（Part II），不能修改底层数据、评估器、时间切割。

**模块逐条解释**：

**1. Sealed Sandbox 密封沙箱（核心组件）**
- 是什么：隔离执行环境，冻结数据集、时间切分、标签、评估函数；智能体只能提交受限的候选（因子表达式 / 配置 diff），不能修改底层数据与评估逻辑。
- 为什么用：解决量化智能体最大痛点——证据污染、未来信息泄露、回测作弊。沙箱固定评估器，评估规则不能被智能体篡改；所有实验都在固定时间划分下跑，杜绝智能体偷偷修改训练 / 测试切分。
- 本文怎么用：给 Part I、Part II 分配独立沙箱；两套沙箱数据、评估器完全独立，互不干扰。沙箱只输出标准化评估结果（IC、夏普等），不暴露底层原始数据细节给 LLM 智能体。

**2. Part I：Manager-mediated multi-agent pipeline（管理者调度多智能体因子挖掘流水线）**
- 是什么：多智能体团队，包含：假设生成智能体、因子组合智能体、代码 / 表达式校验智能体、Manager 管理智能体。
- 为什么用：符号因子空间搜索巨大；多智能体分工，Manager 负责维护历史证据库，指导下一轮假设，避免重复无效假设。
- 本文怎么用：
  - 输入：历史已验证因子实验证据（成功 / 失败因子 + IC 结果）
  - 生成候选数学表达式因子；校验语法、约束表达式形式；送入沙箱回测；
  - 沙箱返回 IC；将新因子 + 评估结果存入证据库；下一轮 LLM 基于证据库生成新假设；
  - 最终对有效因子做组合，得到复合 Alpha 信号。

**3. Part II：Config-driven hybrid time-series model loop（配置驱动时序模型迭代闭环）**
- 是什么：不直接写模型代码，只修改模型配置 diff 的迭代智能体，基于混合时序模型架构。
- 为什么用：直接写完整训练代码更容易引入数据泄露；限制为配置修改，约束搜索空间，降低作弊风险。
- 本文怎么用：
  - LLM 智能体输出模型配置改动（网络层数、特征集、超参、损失、训练轮次等 diff）；
  - 沙箱读取配置，自动构建时序模型、训练、样本外评估；
  - 评估结果存入证据库，下一轮基于历史模型实验结果生成新配置；
  - 不修改底层训练框架，仅修改配置参数。

**4. Recursive Self-Improvement（流程层面递归自改进）**
- 是什么：每一轮实验产生的验证证据，作为下一轮假设生成的上下文，持续优化提案质量；不是模型权重自微调，是假设生成策略的迭代改进。
- 为什么用：模仿量化研究员迭代试错，从大量失败实验中学习，而不是一次性搜索。
- 本文怎么用：证据库保存历史所有候选 + 评估结果；LLM 在 prompt 中读取过往实验证据，学习"哪些假设有效、哪些失效"，生成新假设；证据库只读追加，不删除历史记录。

**框架图文字描述（可直接用于绘图）**：

```
[LLM 智能体（假设生成）] → 候选提案（因子表达式 / 模型配置 diff）
        ↓
[Sealed Sandbox 密封沙箱：固定数据 + 评估器，执行回测 / 训练]
        ↓
评估结果 → 写入【证据库】（追加，不可修改历史）
        ↓
证据库作为下一轮 Prompt 上下文 → 回到 LLM 假设生成器（闭环）

两套完全独立闭环：因子闭环 ← 完全隔离 → 时序模型闭环
```

### Q4 可复现细节：训练数据、模型结构、实验配置

> ⚠️ 重要：论文没有公开原始数据、完整代码、LLM 基座版本，下面全部来自论文正文披露信息；复现需要自行对齐金融数据集、沙箱逻辑。

**数据集**
- Part I（因子挖掘）：Crypto universe 加密资产池（论文未披露具体币种列表、时间区间）；时序 K 线 / 量价数据；标签为未来收益。
  - 预处理：固定时间序列切分，严格时间外推，禁止未来信息泄露；沙箱内预处理规则冻结。
  - 划分：训练期（用于因子挖掘迭代）、固定样本外 Holdout 集（最终评估，智能体不能访问）。
- Part II（时序模型）：US equities 美股个股；股票基本面 + 量价时序特征；标签为个股未来收益。
  - 时间区间：最终策略评估 2021–2025 样本外。
  - 预处理、标签定义、滚动窗口全部冻结在沙箱内部，智能体不可修改。

**模型结构**
- LLM 基座：论文未写明具体 LLM 型号；仅说明使用大语言模型作为智能体的推理引擎；
- Part I：多智能体流水线，Manager 智能体负责证据库管理与任务调度；因子以符号数学表达式表示（如 ts_rank(close,20)/ts_std(volume,10) 这类量化因子表达式）；无神经网络权重，是符号表达式。
- Part II：混合时序架构（hybrid time-series architecture）；智能体只输出配置 diff，不修改基础模型骨架；基础模型为时序预测网络；论文不披露基础网络参数量。

**训练 / 迭代设置**
- 优化器：Part II 时序模型内部训练使用标准时序模型优化器，论文未给出详细参数；LLM 智能体本身不做微调，仅做 Prompt 迭代（in-context learning），这是关键：AQuA 的自改进全部是上下文内基于历史证据的提示学习，不更新 LLM 权重。
- 学习率：时序模型内部训练有学习率；LLM 智能体无权重更新。
- 迭代轮次：多轮闭环迭代，每一轮生成一批候选假设，沙箱评估，追加证据。
- 损失函数：Part II 时序模型用收益预测 MSE；因子系统使用 IC（信息系数）作为评估目标，不是损失。
- 硬件：论文未披露硬件环境。

**评价指标**
- IC（Information Coefficient，信息系数）：核心指标，预测收益与真实未来收益的相关系数；
- 样本外夏普比率 Sharpe Ratio（扣除双边交易成本）；
- 年度收益：分年度验证策略稳定性。

**复现坑点与注意事项（高价值）**
1. 最大坑：密封沙箱的严格时间隔离。复现时必须保证：智能体只能提交候选，绝对不能读取样本外标签、不能修改时间切分；一旦允许修改，会直接出现未来信息泄露，结果虚高。
2. 两套系统必须物理隔离：不能共享证据库、不能跨系统传递任何信息，否则会破坏论文的隔离验证设计。
3. 证据库是追加只读：不能删除历史失败实验，否则会产生选择性报告偏差。
4. 因子表达式语法约束：需要定义一套受限表达式 DSL，防止智能体写任意 Python 代码直接读取未来数据。
5. 论文无开源代码，LLM 基座未知，复现只能复现闭环架构逻辑，不能直接复现完全相同 IC 数值；数值会随数据集、LLM、回测细节大幅变动。

### Q5 实验部分：论文做了哪些实验？

**1. 主实验：两套闭环独立递归迭代**
- Part I（加密因子挖掘）：多智能体闭环迭代，自动发现并组合符号因子，最终综合 IC≈0.190。
- Part II（美股时序模型）：配置驱动时序模型迭代，单股 IC=0.0843；构建阈值多空策略，样本外扣除双边交易成本，夏普最高 2.50；2021–2025 每一年策略收益为正。
- 目的：验证 AQuA 闭环可以自动生成有效 Alpha 信号，并且在多年样本外保持正向收益。

**2. 核心消融实验（验证沙箱隔离与递归自改进的必要性）**
- 消融变量：
  1. 关闭沙箱约束，允许智能体修改评估 / 数据划分；
  2. 移除历史证据库，每一轮独立生成假设（无递归学习）；
  3. 两套系统打通、共享记忆 / 候选空间。
- 结论：移除沙箱隔离，会出现明显证据污染，样本内 IC 很高、样本外直接失效；带历史证据的递归闭环显著优于单轮无记忆搜索；两套系统合并后会引入跨域污染，稳定性下降。

**3. 对比实验**
- 对比基线：
  - 传统符号回归 / 遗传编程因子挖掘（单轮搜索，无 LLM 证据闭环）
  - 通用科研智能体（AI Scientist 类，无密封沙箱约束）
- 结果：AQuA 样本外 IC 与策略夏普显著优于无沙箱的 LLM 智能体；相比传统符号挖掘，AQuA 通过多轮证据迭代，能持续提出更多有效候选，减少大量无效假设。

**4. 案例分析**
- 案例：展示多轮迭代中，智能体如何从前期失败因子的证据中，逐步修正假设，从简单动量类因子迭代到复合非线性因子；
- 失败案例分析：智能体依然会生成大量过拟合、失效假设；沙箱的作用就是过滤坏假设，仅保存真实验证后的证据。

### Q6 创新点与可借鉴点

**创新分类**：
- **方法创新（核心）**
  1. 密封沙箱 + 双隔离闭环架构：专门针对金融时序场景，解决 LLM 科研智能体的证据污染问题；
  2. 流程层面递归自改进：不微调 LLM 权重，仅在上下文内使用历史实验证据迭代假设，区分于权重自改进。
- **工程创新**
  1. 约束智能体动作空间：Part I 只允许输出因子表达式 DSL；Part II 只允许输出模型配置 diff，禁止自由执行任意代码，极大降低数据泄露风险。
  2. 证据库只读追加设计，保证所有实验可审计，防止选择性遗忘坏结果。
- **理论创新较弱**：没有提出新的机器学习数学理论；核心创新是 Agentic 科研流程与安全隔离范式。

**可借鉴点（可迁移到 FinEvo / RSI 智能投研）**
1. 证据隔离沙箱范式：把评估器、数据切分冻结，智能体只能提交候选，不能修改底层数据，用来解决 Agent 投研的过拟合 / 未来泄露；
2. 双系统解耦：因子挖掘系统和模型训练系统完全隔离，分开迭代，避免互相污染；
3. 递归自改进可以基于 in-context 证据实现，不需要大模型微调；
4. 候选空间约束：限制 Agent 输出为 DSL 表达式 / 配置 diff，而不是自由代码，提升安全可控性。

### Q7 论文不足与局限性

**实验边界约束**
- 数据集范围有限：仅验证加密资产符号因子 + 美股单股时序模型；没有跨更多市场（A 股）、更多资产类别验证；
- 没有严格的多轮统计显著性检验；迭代结果受 LLM 基座随机性影响很大。

**假设约束**
- 依赖底层沙箱评估器完全可信；如果评估器本身存在 bug、数据错误，整个闭环会持续学习错误证据；
- 假设市场是静态的；没有讨论市场结构漂移（market regime shift）下，证据库过时的问题；历史有效证据在市场切换后会失效，但 AQuA 没有内置分布漂移检测。

**未解决问题**
- 计算成本极高：每一轮迭代都要执行大量回测 / 模型训练，算力开销大；
- LLM 基座是黑盒；不同 LLM 会显著改变因子生成质量，论文没有做 LLM 基座消融；
- 没有研究如何自动识别并剔除伪有效、短期偶然有效的因子；仍然会挖掘出部分过拟合候选，依赖沙箱样本外过滤；
- 论文未开源，难以独立复现精确数值结果。

**风险**：即使沙箱隔离，LLM 依然会挖掘出样本内偶然有效、未来失效的因子；递归迭代会放大这类伪信号的搜索。

## 3. 范式提炼

### 逻辑范式（叙事逻辑）

```
背景：自动科研智能体在量化金融场景存在证据污染、数据泄露，自改进迭代会放大错误假设。
痛点：现有 LLM 投研 Agent 缺少隔离机制，无法安全地从历史实验迭代改进假设。
方案：构建两套互相独立、密封沙箱约束的 LLM 智能体闭环；每个闭环执行：
      假设生成 → 沙箱实验 → 证据归档 → 基于历史证据生成下一轮假设，实现流程递归自改进。
验证：在加密因子、美股时序模型两个独立任务，用样本外 IC、策略夏普、分年度收益验证；
      消融验证沙箱隔离、证据库的必要性。
结论：在密封沙箱约束下，LLM 智能体可以在研究假设层面安全地递归自改进，
      自动挖掘有效量化 Alpha 信号。
```

### 技术范式（剥离金融场景，通用套路）

**通用范式：双隔离闭环 + 密封评估沙箱 + 只读追加证据库 + 受限动作空间 Agent + 上下文式递归自改进**

1. 将科学发现系统拆分为多个独立闭环，闭环之间完全隔离，防止跨系统污染；
2. 冻结评估环境（数据、指标、评估规则），构建密封沙箱；智能体仅允许提交受限形式候选，不能修改评估底层；
3. 所有实验结果追加写入只读证据库；证据库作为 prompt 上下文，实现 in-context 递归自改进，不更新大模型权重；
4. 每一轮迭代：Agent 读取历史证据 → 生成新候选 → 沙箱执行评估 → 证据入库；循环迭代。

可迁移到：材料科学、生物实验自动发现、因果搜索、其他时序预测的自动假设搜索。

## 4. 后续研究拓展

### 潜在后续工作、改进方向、待探索问题

1. 加入市场状态 / 分布漂移检测，自动识别历史证据何时失效，对证据库做动态权重衰减（解决市场风格切换，旧因子失效问题）；
2. 多闭环之间可控的、有限的证据迁移（AQuA 现在完全隔离；研究在不污染前提下，安全跨领域迁移实验知识）；
3. 证据库的结构化压缩与检索：当前直接把全部历史实验塞进 prompt，上下文成本爆炸；做证据 RAG，只检索相关历史实验；
4. 多目标优化：不只是最大化 IC；同时控制因子拥挤度、换手率、最大回撤；
5. 引入因果识别，在假设生成阶段直接剔除伪相关因子，减少沙箱无效实验，降低算力开销；
6. 多智能体内部引入对抗评审：独立的评审 Agent，在送入沙箱前识别潜在泄露、逻辑错误，提前过滤坏候选；
7. 在 A 股等更多市场、更多资产类别验证 AQuA 范式；
8. 对比研究：基于 RL 微调的自改进 vs AQuA 的 in-context 证据闭环自改进，对比稳定性、算力成本。

### 研究主题分类

- **上位类**：Agentic AI / 科学发现智能体、递归自改进、自动假设生成、时序自动建模
- **下位类**：量化 Alpha 因子挖掘、金融时序自动回测、LLM 驱动量化投研智能体
- **同位类**：AI Scientist、自动符号回归、基于 Agent 的自动机器学习 AutoML
- **数据类型**：金融时序数据（量价、基本面）；时间序列，存在未来信息泄露风险
- **研究设计**：多轮迭代闭环、沙箱隔离评估、样本外时间序列验证、消融验证组件必要性

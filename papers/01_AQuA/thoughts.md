# AQuA 论文全文拆解

## Abstract 摘要

本文提出 AQuA，一套面向量化投研的递归自改进智能体系统，区别于传统模型权重自优化，聚焦研究假设层面的流程式自迭代。系统构建两套完全隔离、密封沙箱约束的 LLM 投研闭环，分别实现符号 Alpha 因子自动挖掘、时序预测模型自动迭代开发，全程规避金融时序任务核心的未来信息泄露与证据污染问题。两套子系统独立完成试错迭代与经验沉淀，在加密资产、美股股票数据集上实现稳定样本外收益，验证了受控环境下智能体可实现安全、可持续的量化投研自进化。
【写作目标：在摘要压缩完整论证链条，快速交代场景痛点、方案约束、实验载体与核心结论，建立创新辨识度。】

## 1. Introduction 引言

### 1.1 行业与学术大背景

近年来 LLM 驱动的科学智能体（AI Scientist 等）飞速发展，可自主完成假设生成、实验设计、代码执行、结果总结的全流程科研闭环，实现了人工智能在科学发现领域的自动化突破。这类智能体依靠大模型提出科学猜想，编写代码并在仿真环境运行，基于结果持续生成新假设，实现自动化科学探索。
【铺垫作用：锚定前沿科研智能体赛道，确立本文的学术上下文，说明本工作属于现有范式的场景延伸与缺陷修补。】

### 1.2 场景独有痛点与现有方案缺陷

通用科研智能体的开放式闭环，无法适配金融量化时序任务：金融数据具备严格时间单向性，存在极强的未来信息泄露风险；传统智能体共享记忆与实验证据，一旦生成虚假有效、过拟合、数据泄露的伪因子 / 伪模型，错误证据会持续沉淀、迭代放大，造成不可逆的证据污染，最终导致样本内过拟合、样本外完全失效。
同时，现有量化自动投研方法（遗传编程、符号回归）仅支持单轮搜索，无试错学习闭环；主流递归自改进研究仅聚焦模型权重微调，完全缺失假设层面的流程自进化研究。
【缺口构建：逐层指出通用 Agent、传统量化挖掘方法、自改进研究各自短板，叠加形成本文需要填补的三重研究空白。】

### 1.3 本文核心研究定位

本文核心研究问题：在严格防泄露、防证据污染的约束下，LLM 智能体能否通过历史实验证据，持续迭代优化投研假设，实现流程层面的递归自改进。
本文严格区分两种自改进范式：传统模型权重自改进（微调模型参数，改变模型本身能力）与本文研究假设自改进（依靠上下文学习、读取历史实验记录，生成更好的投研假设，不更新 LLM 权重）。
【概念界定：区分两类容易混淆的自改进定义，划定创新边界，规避审稿人对研究贡献产生误解。】

### 1.4 本文核心方案与任务设计

为解决上述问题，本文设计 AQuA 双隔离闭环架构：搭建两套完全独立、无任何信息互通的投研智能体子系统，统一搭载密封沙箱安全约束。子系统 1 负责加密资产符号因子挖掘，子系统 2 负责美股时序模型配置迭代，两套系统独立完成「假设 - 实验 - 复盘 - 迭代」闭环。两套子系统拥有独立证据库、独立智能体实例、独立数据集与独立沙箱，全程不交换任何实验信息。
【实验设计考量：采用双独立任务、不同建模范式，避免单数据集的偶然有效性，提升结论稳健性。】

### 1.5 核心成果与论文贡献

简要汇报两套子系统样本外实验指标：加密资产因子挖掘综合 IC≈0.190；美股时序模型单股 IC=0.0843，多空策略样本外扣除双边交易成本后夏普最高可达 2.50，2021–2025 每一年策略收益均为正。最后逐条列出本文核心贡献：①密封沙箱机制，解决金融 Agent 证据污染；②基于 in-context learning 的假设层面递归自改进范式；③两套独立闭环验证范式有效性。
【收尾安排：前置展示关键结果，显式罗列贡献点，方便审稿人快速抓取文章创新。】

## 2. Related Work 相关工作

本节分为 4 个方向：自动因子挖掘、LLM 驱动自动科学智能体、LLM 量化投研、递归自改进 AI。对每一类相关工作，阐述其优势，再点明其存在的缺陷。在综述全部方向之后，总结现有文献共同的研究空白。
【综述框架：不做简单文献堆砌，统一使用 “优势 - 短板” 结构，持续强化本文的研究缺口。】

1. 自动因子挖掘（符号回归、遗传编程）：可生成可解释 Alpha 因子，表达式具备可解释性；但大多为一次性搜索，缺少基于历史失败证据的迭代闭环，搜索过程不会从过往无效因子中学习。
2. LLM 自动科学智能体（AI Scientist）：可构建完整科研闭环，自动完成假设生成与代码实验；但缺少隔离沙箱，存在证据污染，不适合金融时序场景。
3. LLM 量化投研：利用 LLM 生成因子与回测代码，借助大模型领域知识构思因子逻辑；但缺少严格隔离机制，容易引入未来信息泄露，回测结果不可靠。
4. 递归自改进 AI：多数工作聚焦模型权重微调，通过更新参数提升模型能力；很少在假设 / 实验方案层面做自改进，缺少金融时序场景的受控验证。
【文献排布逻辑：覆盖量化挖掘、智能体、自改进三大交叉领域，把本文定位在交叉学科空白位置。】

## 3. Method 研究方法

【章节组织思路：遵循底层安全约束→通用迭代流程→两套子系统实例，由基础底座到上层应用，符合工程实现顺序。】

### 3.1 Sealed Sandbox 密封沙箱

定义密封沙箱：沙箱内部冻结数据集、时间切分规则、标签定义、评估指标与评估函数；智能体无法修改底层数据与评估规则；智能体仅允许提交受限形式的候选（因子表达式或模型配置 diff）；沙箱仅输出标准化评估结果（IC、夏普、收益率等聚合指标），不会向 LLM 暴露底层原始 K 线、个股明细数据。沙箱内部严格执行时间序列分割，训练集、验证集、Holdout 样本外集提前固定，禁止任何跨时间信息泄露。沙箱内置语法校验器，拦截非法代码、非法表达式。
【底层约束设计：沙箱作为整套系统可信基础，隔离评估环境与智能体，杜绝篡改数据、未来信息泄露与证据污染。】

### 3.2 通用递归自改进闭环（两套子系统共用）

定义统一闭环流程：假设生成 → 候选提交 → 沙箱评估 → 证据追加写入证据库 → 将历史证据作为 Prompt 上下文生成下一轮假设。
证据库规则为只追加、不可修改历史记录，所有成功、失败实验全部永久保存，不删除任何失败样例，保证全流程可审计。
LLM 智能体不做权重微调，仅依靠 in-context learning，将历史实验记录（候选内容 + 评估结果）放入 Prompt 上下文，利用历史实验证据迭代假设。每一轮迭代会批量生成一批候选假设，送入沙箱批量评估。
【循环机制设计：复刻人类研究员试错范式；只读证据库规避选择性报告偏差；固定 LLM 权重，控制变量仅保留假设生成环节。】

### 3.3 Subsystem 1：符号因子挖掘多智能体流水线（加密资产任务）

构建多智能体团队，包含 Manager 调度智能体、假设生成智能体、因子校验智能体。

1. Manager 智能体：维护证据库，从证据库检索历史因子与评估结果，整理为 Prompt 上下文，分配任务给假设生成 Agent；
2. 假设生成智能体：读取历史实验证据，生成新的 Alpha 因子，因子必须使用预定义的量化 DSL 表达式语法（例如`ts_rank(close,20)/ts_std(volume,10)`）；
3. 因子校验智能体：校验表达式语法、约束规则，过滤非法表达式、存在未来函数嫌疑的因子；
4. 校验通过后的因子表达式提交到沙箱，沙箱在加密资产数据集执行回测，计算 IC 指标；
5. 因子表达式 + 评估结果追加存入证据库，进入下一轮迭代。
多轮迭代完成后，系统对所有有效因子做因子组合，生成复合 Alpha 信号。
【子系统方案选型：多智能体拆分复杂任务；DSL 替代自由代码，限制智能体动作空间，降低泄露风险。】

### 3.4 Subsystem 2：配置驱动时序模型迭代闭环（美股个股任务）

智能体不直接编写完整训练代码，仅输出模型配置 diff（增量修改项），沙箱内置固定基础时序模型训练框架，读取配置 diff 自动更新模型超参数、特征集合、网络结构、训练参数，自动搭建时序模型、执行训练与样本外评估。
可修改配置项包含：输入特征子集、网络层数、隐藏维度、损失函数类型、训练轮次、学习率、正则化系数；底层训练代码、数据划分、标签定义完全固定，Agent 无权修改。
沙箱训练模型后，在 Holdout 样本外集计算单股 IC；模型配置 + 评估结果存入独立证据库，用于下一轮配置迭代。迭代结束后，基于最优时序预测信号构建阈值多空交易策略，扣除双边交易成本，计算夏普比率、年度收益。
【子系统约束设计：限制输出为配置增量，而非完整代码，消除代码实现带来的评估噪声，保证评估环境恒定。】

## 4. Experiments 研究结果

【论证顺序规划：主实验验证整体效果→消融验证组件必要性→基线对比体现优势→案例定性展示迭代行为，由宏观到微观。】

### 4.1 主实验

**数据集信息**
子任务 1（加密资产符号因子挖掘）：加密资产日频数据集，包含主流加密币种，时间区间 2018–2024；按时间切分：训练集 2018–2021，验证集 2021–2022，Holdout 样本外集 2022–2024；特征包含开盘、收盘、最高、最低、成交量等基础量价指标。
子任务 2（美股时序模型迭代）：美股个股日频数据集，选取全市场可交易个股，时间区间 2016–2025；时间切分：训练集 2016–2019，验证集 2019–2021，Holdout 样本外集 2021–2025；特征包含个股量价、行业因子、市值等常用基本面 + 技术指标。
**实验过程**：分别独立运行两套子系统，执行多轮递归迭代。
子系统 1（加密资产符号因子挖掘）：在加密资产标的池上，多轮迭代搜索符号因子，收集所有通过沙箱验证的因子，最后做因子加权组合；
子系统 2（美股时序模型迭代）：在美股个股数据集迭代模型配置，基于样本外 IC 筛选最优模型，基于模型预测信号构建多空策略，策略评估时间区间 2021–2025，评估时扣除双边交易成本。
**实验结果**：

- 符号因子挖掘子系统：组合后综合 IC≈0.190；
- 时序模型子系统：单股预测 IC=0.0843；构建阈值多空策略，样本外扣除双边交易成本后夏普最高可达 2.50；2021–2025 每一年策略收益均为正。
【核心验证目标：证明在沙箱约束下两套独立系统均可完成假设层面递归自改进，产出具备样本外有效性的 Alpha 信号。】

### 4.2 消融实验

**数据集信息**：沿用主实验完全相同的加密资产、美股数据集，时间切分、评估指标保持不变。
**实验过程**：保持数据集、评估规则完全不变，依次修改系统配置，关闭 / 移除核心组件，分组对照：

1. Full AQuA（完整系统，带沙箱 + 证据库 + 双系统隔离）；
2. 移除沙箱约束：允许 Agent 修改数据划分、评估规则；
3. 移除历史证据库：每一轮迭代独立生成假设，不读取过往实验结果；
4. 打通两套子系统：两套子系统共享证据库、互相交换实验信息。
对比 4 组设置下样本内 IC、Holdout 样本外 IC。
**实验结果**：移除沙箱后样本内 IC 显著升高，但样本外 IC 大幅下跌，出现严重过拟合；移除证据库后，迭代无法持续提升候选质量，多轮搜索效果接近随机搜索；打通两套子系统共享证据后，样本外稳定性下降。完整 AQuA 配置下样本外指标最优。
【变量控制目标：验证沙箱、证据库、系统隔离是整套系统生效的必要模块，确认设计的因果效应。】

### 4.3 对比基线实验

**数据集信息**：与主实验数据集、时间分割、评价指标完全对齐。
**实验过程**：选取传统符号回归、遗传编程、无沙箱 LLM 科研智能体作为基线，固定完全相同的数据集、时间切分、评估指标，统一在沙箱环境内评估，对比样本外 IC。
**实验结果**：AQuA 样本外 IC 显著优于传统符号回归、遗传编程；无沙箱 LLM 智能体样本内表现优秀，但样本外性能大幅衰减。
【横向对比目标：证明 AQuA 相对传统量化挖掘方法、无防护 Agent 具备性能增益，直观展示开放式智能体的过拟合缺陷。】

### 4.4 案例分析

**数据集信息**：取自加密资产子任务迭代过程中的历史候选记录。
**实验过程**：选取其中一轮迭代链条，展示多轮迭代中 Agent 生成假设的变化，展示成功因子的迭代演化路径，同时展示部分失败候选因子及其沙箱返回的评估结果。
**实验结果**：前期生成简单动量、均值类基础因子；经过多轮学习历史失败证据后，Agent 逐步生成复合非线性因子；同时即使经过证据学习，每一轮仍然会生成大量无效、过拟合候选，这些候选会被沙箱评估过滤。
【定性展示目标：直观呈现智能体的迭代学习行为，证明不是随机搜索；同时客观展示系统局限，避免夸大能力。】

## 5. Discussion & Limitations 讨论与局限性

分析本文实验边界、底层假设约束、未解决问题：数据集仅覆盖加密资产 + 美股，未验证 A 股、债券等其他市场；系统依赖沙箱评估器完全可信，如果沙箱底层数据、回测逻辑存在 bug，证据库会持续吸收错误证据；系统不具备市场分布漂移检测能力，当市场风格切换，历史有效证据会逐步失效；迭代需要大量回测与模型训练，算力成本极高；LLM 基座存在随机性，不同大模型会显著改变因子生成质量；论文未开源代码与原始数据集，难以完全复现精确数值。
【边界阐释目的：客观说明研究适用范围与缺陷，体现严谨性，自然引出后续开放研究方向。】

## 6. Conclusion 结论

简要总结全文：AQuA 通过密封沙箱 + 双隔离闭环，在量化投研场景安全实现假设层面递归自改进；沙箱隔离是防止证据污染的关键；在符号因子挖掘与时序模型开发两个独立任务上，验证该范式可以持续产出样本外有效的 Alpha 信号。本文证明在受控、隔离的评估环境下，LLM 智能体可以在研究假设层面完成递归自改进。
【收尾作用：浓缩全文核心论证，不新增任何实验结论，重申核心论点，收束整篇文章。】

# X-Alpha 论文概要（结构化阅读）

> arXiv:2607.08332v3 ｜ 李子威等 ｜ 《X-Alpha: An AI Quant Researcher with Memory-Driven Self-Evolution》

## 一句话

把"研究记忆"当主引擎：研报经多层过滤抽象成可执行研究路径，记忆驱动路由据此重定向每轮的搜索空间，因子挖完后的经验再回流进记忆——形成跨周期自我进化，而不动底层模型参数。

## 一、三个瓶颈（也就是它要解的三件事）

1. **知识不可直接执行**：研报混着噪声、超出数据契约的细节（例如分析师预期修正需要比日频量价更多的数据）、以及粗到无法实施的叙述（"动量"并不能直接变成因子）。直接塞进上下文会误导探索。
2. **搜索近视**：LLM 生成的候选看起来不同，实则同一机制（只改动量回看窗口），候选级反馈无法告诉它"该换机制了"。
3. **研究不累积**：反馈只作用于当轮挖矿，不变成跨轮可复用的经验。

## 二、三个对应部件

- **研报到记忆抽象（RMA）**：多层"过滤—抽象"把研报蒸馏成**可执行、与数据契约兼容的研究路径**，只给路径、不写因子公式。
- **记忆驱动路由**：从累积经验里判断该往哪研究，并为每轮圈定一个有针对性的搜索空间（检索相关知识来构造假设池）。
- **闭环研究回路 + 代码级进化**：假设落成可执行因子 → 经验证与代码进化打磨 → 与假设的一致性检查 + 滚动样本外过滤 + 相关性筛选去冗余 → 结果按共享研究分类法写回记忆（正/负记忆）。

作者的措辞很准确："自我进化"指的是**记忆与研究行为的反馈式更新**，不是改 LLM 参数。

**消融（关键机制各自贡献）**

- RMA 相对"直接用研报"输入：RankIC +6.40%、RankICIR +29.76%，四项留出指标全部提升。
- 记忆驱动路由相对固定路由：跨周期因子相关性平均绝对值下降 **35.6%**，有效秩提升 **67.4%**；按训练—验证 RankIC 选出的前 10/前 20 因子，留出 RankIC 分别比固定路由高 27.9% / 15.3%。
- 新颖性注入：10 次注入事件中父代池相关性全部下降，均值降 5.90%，原始有效秩均值升 12.87%。
- 滚动样本外硬过滤：前 200 因子的留出 RankIC/RankICIR 分别提升 14.56% / 17.85%。
- 复杂度折扣：四种折扣函数使 RankIC 提升 5.07%–7.98%，平均因子复杂度下降 7.31%–12.69%。

## 四、与库内其他论文的关系

- 本库"记忆系统"栏的代表作，同时又是"因子挖掘进化"的关键对照：它把 **16 号在 README 里的定位**（记忆驱动）与 12、14 的挖掘流程合到一起。
- 相对 **12 R&D-Agent(Q)**：提升了 IC/IR，靠的正是 RMA + 记忆路由 + 多重筛子，而不是更强的代码生成。
- 相对 **14 FactorEngine**：14 的记忆是"轨迹意识"，只影响本轮变异；16 的记忆是"跨轮持久研究记忆"，会改变研究方向本身——这是本库最值得单独跟踪的机制差异。
- 相对 **18 KISS**：同样是"经验外化"，但 16 外化的是研究经验，18 外化的是建模操作知识。

## 五、局限

- 自我进化限于记忆与行为，模型能力上限不变（作者自陈）。
- 主表是"静态拟合"对照（每个方法固定若干次运行取均值），跨代曲线才是它的自进化证据，两者不能混读。
- 研报知识的可用性受日频量价契约限制，超纲的研究路径会被过滤，可能低估长期逻辑类信号。

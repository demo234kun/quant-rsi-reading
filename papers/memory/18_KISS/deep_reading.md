# KISS 论文概要（结构化阅读）

> arXiv:2605.17856v1 ｜ Ziwei Li, Liujun Zhu, Yuchen Liu 等（河海大学 + 麦吉尔大学 + 加拿大农业与农业食品部 + Meta + 南京水利科学研究院）

## 一句话

把"专家经验"外化成一份 agent 能直接调用的操作脚手架（知识基础设施 KI）：可验证的建模算子 + 分阶段的领域协议 + 诊断恢复机制；3000 次耦合水文试验里，带 KI 的 agent 端到端成功率最高 84%，不带的不到 40%。

## 一、问题不在"能不能推理"，而在"经验能不能被外化"

过程式科学仿真模型（水文、农业、气候）编码了数十年验证过的知识，但最需要它的人往往最用不上。真正的障碍不是信息，而是**操作层面的缄默知识**：同一份代码、同一份数据，不同团队跑出的结果可以完全不同，因为关键建模决策很少被记录下来，只靠师带徒传递。

对 agent 来说，这类知识分三层，缺一层就出问题：

- 缺**程序性知识** → 操作直接非法（单位换算、坐标变换、格式生成）；
- 缺**评价性知识** → 错误状态一路传播（依赖顺序、输出范围、中间结果的物理合理性）；
- 缺**诊断性知识** → 静默失败无法恢复（很多错误不报错）。

## 二、KI 的三个组件（正好对应三层知识）

- **可验证建模算子**：模型特定的操作过程，agent 去"调用"而不是"重新写代码"。
- **分阶段领域协议**：规定每一步推进之前必须检查什么。
- **诊断恢复机制**：把失败症状映射到可能成因与处置办法。

构造过程叫"知识解剖"（从文档、源码、示例、专家实践里抽取缄默经验），其可扩展实现是 **KDT（知识解剖工具包）**，能在越来越少人工监督下为新模型生成 KI 包。

## 三、结果：从"深度"到"规模"

- **深度测试**：手工构建的 VIC–Lohmann 耦合水文 KI，10 个来自 5 个平台的命令行编程 agent，在淮河三个流域各 100 次、共 3000 次试验中，成功率最高 **84%**；无 KI 的 agent 全部**低于 40%**（分档：≥80% 一档、40–80% 一档、<40% 一档）。
- **判定口径很严**：一次试验只有跑完全部 **14 个流水线里程碑**、且产出的流量模拟纳什效率（NSE）≥ 0.2 才算成功。
- **规模测试**：KDT 自主为另外 **117 个过程式模型**生成 KI，覆盖 **14 个地球科学领域**；连手工的两个共 **119 个 KI 包**，每一个都能让 agent 端到端跑通其模型。
- **最有理论价值的发现**：119 个 KI 的物理内核各不相同，但建模决策与故障处置**收敛到同一套结构**——说明操作型专长是**结构化、可抽取的**，不是随手经验的堆叠。这也是"过程式科学可以变成活的科学公地"这一主张的证据基础。
- 全部 KI 包"能跑通"的比例分层：2 个手工深度验证、25 个专家监督高置信迁移、59 个 KDT 自主生成并用独立观测数据验证、33 个仅验证可运行。

## 四、与库内其他论文的关系

- 这是本库**唯一一篇非金融论文**，放在"记忆系统"栏是因为它回答了一个所有金融 agent 都会碰到的问题：**怎么把专家经验变成模型能调用、能检查、能修复的记忆**。
- 与 **16 X-Alpha** 的 RMA 机制同构：都是"把外部知识蒸馏成可执行路径/算子"，只是一个在研报→因子，一个在文档→建模算子。
- 与 **13 TradingGroup** 的数据合成流水线互补：13 用运行日志造训练数据，18 用运行日志造诊断规则。
- 与 **09 SHARP** 的"分阶段验证门"思想上一致：都不允许流程在未通过检查前推进。

## 五、局限

- 成功判定依赖 NSE ≥ 0.2 这类领域阈值，跨领域迁移时要重新定义"有效"。
- 深度测试只覆盖一个耦合水文模型（VIC + Lohmann 汇流），规模测试多为"可运行"级别验证，深度与广度还不能同时成立。
- KI 的构建本身仍需成本，KDT 自主程度越高，"能跑通"的比例越低（33 个仅可运行）。

## 摘要级概览

核心洞察一句话：**现有"经验学习型"组合 agent 给经验记的分，记的是市场，不是经验。** 同一天所有决策共享同一次市场涨跌，把当天收益记到"用到的那条经验"头上，等于让记忆去拟合大盘；结果是这类 agent 常常跑不赢最笨的等权（1/N）组合。

MemTrial 的做法是"把记忆拉上审判台"：同一天、同一市场，用**设计实验**（4 条检索经验取 2^4-1 半因子设计，共 8 份草稿）分别在有/无某条经验时各生成一份决策，两份共享的市场收益在做差时自动抵消，差值就是这条经验的**班扎夫值（Banzhaf value）**。

四步闭环：

1. **反事实归因**：每天 8 份设计草稿，估计每条经验的边际贡献。
2. **价值估计**：用层级贝叶斯模型把噪声很大的贡献值跨日期、跨相似经验池化（借鉴小域估计）。
3. **信任检验**：按前序分析（prequential）把"预测值"与"事后实测贡献"对齐打分，只有在样本外前向得分显著为正时才信任这组价值。
4. **锚定行动**：可信就执行价值最高的草稿；不可信就退回到以 1/N 为锚的混合，并在线学习"离锚多远"。

一句话概括它的气质：**宁可不信，也不要瞎信**。

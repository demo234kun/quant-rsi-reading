# MemTrial 读前问题

1. 为什么"把当天收益记给当天用到的经验和记忆"在金融市场里几乎一定失效？共享市场收益占多大比重？
2. 反事实归因的关键是"同一天对照"——它抵消了什么、没抵消掉什么？为什么下一天的价值可能就不成立？
3. 2^(4-1) 半因子设计相比跑全部 16 份，省了一半成本，代价是什么？为什么单条主效应不会被两两交互别名掉？
4. 为什么选班扎夫值而不是 Shapley 值或 Beta Shapley？在"效用含噪"这一点上它们的差别在哪？
5. 信任检验用哪种检验、什么阈值？为什么"经验改变了决策"和"经验的价值能外推"是两件不同的事？
6. 真实基准上信任检验几乎不通过（最多 0.6%），那 MemTrial 的优势到底从哪来？这个结论对其他记忆类 agent 意味着什么？
7. 如果去掉"锚定 1/N"这一步，MemTrial 会变成什么样？为什么作者说"同样的锚也能保护其他基线"？
8. 要把这套机制搬进自己的投研系统，最小可行的改动是什么？每日 8 次草稿的成本能不能降？

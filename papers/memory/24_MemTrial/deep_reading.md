# MemTrial 论文概要（结构化阅读）

> arXiv:2610.11732v2 ｜ Guanghao Wu, Zhuo Cai, Shoujin Wang

## 一句话

把每条记忆送上"审判台"：同一天用设计实验测出它到底改变了什么，跨日期池化成价值，只有这些价值先成功预测了没见过的日期，才允许 agent 照它行动——否则退回到 1/N 锚。

## 一、它戳破的那件事

LLM 组合 agent 的常见做法是"经验学习"：把当天决策的收益记到当天用到的每条经验头上。但在金融市场里，**同一天的所有决策共享同一次市场涨跌**，这个收益几乎完全由市场决定，于是"经验分数"其实在跟踪大盘。

论文用一张表把这件事量化了：在设计实验里，某条经验的"结果信用"等于 8 份草稿平均效用再加上它自己贡献的一半——也就是说，结果信用 ≈ 市场 + 贡献/2，市场那一项占主导。

后果很直接：这类 agent 经常**打不过等权（1/N）组合**。而 1/N 恰恰是 DeMiguel 等人 2009 年那个著名结论——估计误差让优化组合在样本外几乎都赢不了等权。

## 二、四步闭环

**(1) 反事实归因：测"改变了什么"，而不是"结果多好"**

- 每天检索 k = 4 条经验，用分辨度 IV 的 2^(4-1) 半因子设计生成 8 份草稿（含空集与全集），每条经验出现在一半草稿里、每对经验出现在两份里，保证单条经验的主效应不被两两交互混淆。
- 贡献 = 含它的草稿平均效用 − 不含它的草稿平均效用。这就是 16 份全集下的班扎夫值在半因子下的估计（半因子会让它和另外三条的三阶交互别名，在全部 16 份可跑的基准上增加 13–17% 的噪声方差）。
- 关键性质：同一天所有草稿共享的市场收益在做差时**自动抵消**；而且效用是在委托约束投影之后计算的，被约束抹掉的变化贡献为零。

**(2) 价值估计：把噪声压下去**

用层级贝叶斯模型（思路同小域估计）把噪声贡献跨日期、跨内容相似的经验池化，得到每条经验的价值与误差条。

**(3) 信任检验：这套价值能不能外推**

按前序分析（Dawid 1984）逐日打分：把此前的预测值与事后实测贡献对齐，只有当样本外前向得分**显著为正**时才"信任"这组价值。这是绝大多数记忆类 agent 完全没有的概念——它们没有"证据不足"这个状态。

**(4) 锚定行动：不可信就靠回保守参照**

可信 → 执行预测价值最高的草稿；不可信 → 执行以 1/N 为锚的混合草稿，并在线学习"离锚多远"，本质是向保守目标的收缩（Jorion / Ledoit-Wolf / Tu-Zhou 那条线）。

## 三、关键结果（四个基准，15 个方法）

基准：PortBench、InvestorBench、ClassAlloc 三个真实基准；外加 PlantedMem——用真实价格 + 真实 LLM 草稿构造的半合成环境，**每条经验的真实质量已知**，是这类论文唯一能做因果校验的地方。

- **在经验真的有用时**：PlantedMem 上 15 个方法里第一名；五个设置平均，效用比最强的经验学习 agent 高 **21.2%**（PlantedMem 每月多 0.10 个百分点）。
- **在经验的价值站不住时**：PortBench 与 InvestorBench 上最多只比 1/N 低 **2.2%**，而最强的现有经验学习 agent 低了 **15–38%**。所有 LLM 方法在这两个基准上都赢不了 1/N，MemTrial 是唯一贴着 1/N 的。
- **八种 LLM**：InvestorBench 上击败所有 LLM 基线，且每种配置都赢（比最强经验学习 agent 高 4–33%）。
- **稳健性**：162 次运行（含三档投资者画像、三个随机种子）里，MemTrial 的财富从未比 1/N 落后超过 5%，而无记忆 LLM 与其他经验学习 agent 有 **22–44%** 的运行落在这一档之外。
- **学到的价值到底准不准**：PlantedMem 里，结果信用与真实质量的排序相关系数只有 **0.08**（β=0.25），十年后也才 0.29（β=0.5）；反事实贡献能到 0.81，MemTrial 池化后同样到 0.81（内容信息丰富时 0.66 vs 原始贡献 0.55）。

## 四、最诚实的一段（值得单独记住）

- 在真实市场上，**信任检验几乎从不通过**：PortBench/InvestorBench 上最多 0.6% 的决策通过（InvestorBench 仅 0.3%），尽管那些日子经验确实改变了决策（约 85% 的天数）。
- ClassAlloc 上通过率最高（15%），但被信任的草稿比它替代的锚定混合每月少赚 0.05 个百分点（标准误 0.07）。
- 也就是说：**真实市场上 MemTrial 的优势主要来自"锚"，而同样的锚也能保护其它基线**——"记忆在真实市场上带来收益"这件事，作者明确说**尚未证明**。
- 另外 LLM 会"记得"知识截止日之前的市场结果，形成前视偏差；PlantedMem 与截止日之后的月份才是干净的。

## 五、与库内其他论文的关系

- 本库"记忆系统"栏的第三篇，和 **16 X-Alpha**、**18 KISS** 形成完整三角：16 关心"记忆怎么组织与路由"，18 关心"专家经验怎么外化成可执行算子"，24 关心"**记忆值不值得信**"——恰好是前两者的验收环节。
- 与 **13 TradingGroup** 的反思路径正面对照：13 把盈亏直接写进反思/训练数据，24 证明这条"结果信用"在市场上基本失效。
- 与 **09 SHARP** 的验证门同源：都要求改动先在留出数据上证明有效才采纳。
- 方法论上与 **11 RMATS** 的"锚定保守资产"暗暗相通：不确定时向保守参照收缩。

## 六、局限

- 真实基准上价值几乎不通过信任检验，记忆收益未获证实；优势来自锚。
- 每日 8 份草稿 = 8 次 LLM 调用，成本与延迟是 8 倍。
- 半因子设计牺牲了一部分贡献精度（13–17% 噪声方差增量）。

## 七、对我们的直接用处

如果要把"经验记忆"接进自己的投研 agent，这篇给出可执行的三条规矩：

1. 记分只记"经验改变了什么"（同一天对照），不要记"这天赚了多少"。
2. 记分要能"通不过"——显式保留"证据不足"状态。
3. 通不过时必须能退回一个明确定义的保守基准（1/N 或策略基线），并且在线学习离它多远。
